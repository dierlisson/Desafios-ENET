# Desafios ENET

Repositório destinado à organização e resolução dos desafios da **ENET**.

Cada desafio será armazenado em uma pasta própria, facilitando a navegação, a organização do código e o acompanhamento da evolução ao longo das atividades.

## 📁 Estrutura do repositório

A estrutura seguirá o padrão:

```text
Desafios-ENET/
├── desafio-01/
├── desafio-02/
├── desafio-03/
├── ...
└── README.md
```

Cada pasta corresponde a um desafio independente.

## 🚀 Desafios

Conforme os desafios forem desenvolvidos, suas respectivas pastas serão adicionadas a este repositório.

| Desafio | Pasta | Status |
|---|---|---|
| 01 | `desafio-01/` | A adicionar |
| 02 | `desafio-02/` | A adicionar |
| 03 | `desafio-03/` | A adicionar |

> A tabela será atualizada à medida que novos desafios forem incluídos.

## 🧩 Organização

Cada pasta poderá conter os arquivos necessários para a resolução do respectivo desafio, incluindo:

- código-fonte;
- arquivos de configuração;
- documentação específica;
- exemplos ou recursos utilizados;
- um `README.md` próprio, quando necessário.

## ▶️ Como utilizar

Clone o repositório:

```bash
git clone https://github.com/dierlisson/Desafios-ENET.git
```

Acesse o projeto:

```bash
cd Desafios-ENET
```

Depois, entre na pasta do desafio desejado:

```bash
cd desafio-01
```
